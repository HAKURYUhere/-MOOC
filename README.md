# 中国大学 MOOC 待办提醒 Chrome 扩展

这是一个 Manifest V3 浏览器扩展，用来在中国大学 MOOC 首页、“我的课程”页和课程页面中自动收集作业、互评、测验、考试、讨论、问卷等待办任务，并按 1 天、1 周、1 月优先级汇总提醒。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页：`chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录：`mooc-task-assistant`。

## 使用

1. 登录中国大学 MOOC。
2. 打开首页、“我的课程”页、课程页、学习页、作业页或测验页。
3. 点击浏览器右上角扩展图标查看汇总待办。
4. 在弹窗中按“1天”“1周”“1月”“全部”查看不同优先级任务。
5. 如果当前页面刚加载完成，可以点击弹窗右上角刷新按钮重新扫描；在首页或“我的课程”页会自动尝试扫描课程入口。
6. 在“提醒设置”中调整截止前提醒时间和后台检查间隔。

## 说明

- 扩展不会读取账号密码，也不会向外部服务器发送数据。
- 任务数据保存在浏览器本地扩展存储中。
- 首页聚合扫描会自动抓取最多 20 个课程入口，并尝试进入课程中的作业/测验/考试/讨论等子页面。
- `1天` 包含已截止和 24 小时内截止任务；`1周` 包含 7 天内任务；`1月` 包含 30 天内任务。
- 抓取逻辑会优先使用高置信任务条件，过滤课程介绍、公告、评分标准等非任务文本；如果页面没有高置信结果，会启用中置信候选，并在弹窗标记“待核对”。
- 识别会覆盖“未交、待提交、待互评、即将截止”等常见状态，也会尝试从页面脚本 JSON 中提取任务标题和截止时间。
- 中国大学 MOOC 页面结构可能调整；如果部分任务无法识别，可以先进入对应课程的作业/测验/考试页面再刷新扫描。
